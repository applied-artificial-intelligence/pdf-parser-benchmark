## Introduction

PDF-Bench is an open-source benchmarking suite for evaluating PDF-to-Markdown conversion systems. It provides a standardized framework for comparing different parsers and APIs.

## Features

The benchmarking suite includes several key features:

- Support for multiple parser systems
- Comprehensive evaluation metrics
- Caching system for performance
- Extensible architecture
