# PDF-Bench

Open-source benchmarking suite for PDF-to-Markdown conversion.

## Overview

PDF-Bench provides a comprehensive framework for evaluating the quality of PDF-to-Markdown conversion tools and services.

## Installation

```bash
pip install pdf-bench
```

## Quick Start

```bash
pdfbench version
```

## Development

This project uses `uv` for dependency management.

```bash
# Create virtual environment
uv venv

# Install in editable mode
uv pip install -e .

# Install with development dependencies
uv pip install -e ".[dev]"
```
