## Key Findings from Framework Comparison

### Metric Correlation Analysis

| Metric Type | PDF-Bench | OmniDocBench | Correlation |
|-------------|-----------|--------------|-------------|
| Text accuracy | 89.9% edit_similarity | 91.1% (1-Edit_dist) | ✅ Strong (1.2% diff) |
| Table quality | 80.2% TEDS | 68.7% TEDS | ⚠️ Weak (11.5% diff) |
| Structure | 49.3% tree_similarity | 92.7% reading_order | ❓ Different metrics |

### Critical Insight: Table Evaluation Gap

**PDF-Bench synthetic corpus**: 80% TEDS
**OmniDocBench real-world**: 69% TEDS

This 11% gap suggests either:
1. Synthetic tables are easier than real-world
2. OmniDocBench evaluation is stricter
3. Different table complexity distributions

**Recommendation**: Need real-world tables in PDF-Bench corpus
