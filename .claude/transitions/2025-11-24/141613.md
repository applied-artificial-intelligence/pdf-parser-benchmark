## Technical Details

### Result File Aggregation

The published scores (88.4% commercial, 81.3% OS) come from **different document sets**:
- Commercial: 200 documents (Azure/AWS full coverage)
- Open-source: 353 documents (all native PDF corpora)

This explains why head-to-head comparison shows different results.

### Why Invoice Scores Are Low

Azure scores 43.9% on invoices (100 docs = 56% of matched sample), dragging down overall. This is because:
- Invoice ground truth includes table structure
- Text extraction loses tabular relationships
- All parsers struggle with table reconstruction (~50% ceiling)

    try:
        data = json.loads(f.read_text())
        results = data.get("results", [])
        all_results.extend(results)
        for r in results:
            if r.get("metrics", {}).get("edit_similarity") is not None:
                parser_docs[r["parser_name"]].add(r["document_id"])
    except:
        pass

print("Parser coverage:")
for p, docs in sorted(parser_docs.items(), key=lambda x: -len(x[1])):
    print(f"  {p}: {len(docs)} docs")
print(f"\nTotal unique documents: {len(set(r['document_id'] for r in all_results))}")

## Key Insight for Publication

**Do NOT claim "commercial beats open-source by 7pp"** - this compares different document sets.

The accurate story:
1. On matched documents, open-source wins by 6.2pp
2. Domain determines winner (no single parser dominates)
3. Invoice-heavy benchmarks favor open-source
4. Format-agnostic metrics reveal hidden performance (Databricks +14pp)
5. OCR is the real differentiator (only Marker has effective built-in OCR)
