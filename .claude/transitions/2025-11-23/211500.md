## Key Issues Discovered

1. **Commercial benchmark too slow**: 8 parallel workers + commercial APIs = no progress. Need to use 1-2 workers or smaller batches.

2. **Google page limit**: `ai_parse_document` fails on docs >15 pages with "Document pages exceed the limit"

3. **Azure inconsistency**: Some docs get 1-2% scores while similar docs get 80%+

4. **Academic papers hard for all**: Two-column layouts + equations = ~20-30% max for any parser
