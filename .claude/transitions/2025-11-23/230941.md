### Critical Issues Identified

#### Issue 1: Invoice Ground Truth Format Mismatch
**Status**: Diagnosed, fix pending
**Corpora affected**: invoices, hr, legal, synthetic (all DOCX-based)

**Root cause**: Ground truth extracted from DOCX with markdown table format:
```
Description | Quantity | Unit Price | Amount
Enterprise Plan | 45.87 | $71,834.13 | $3,295,031.54
```

But PDF parsers extract raw text without markdown:
```
Description
Quantity
Enterprise Plan
45.87
```

**Evidence**: All parsers score 30-44% on invoices despite correct text extraction
**Fix needed**: Regenerate ground truth from PDF text (not DOCX)
**File to modify**: `builders/generate_invoice_corpus.py` - `extract_ground_truth_from_docx()` function (lines 78-123)

#### Issue 2: Azure Document Intelligence 2-Page Limit
**Status**: Diagnosed, user checking Azure tier
**Symptom**: Azure returns only 2 pages for ALL multi-page documents

**Evidence**:
- cuad_007.pdf: 11 pages (pdfinfo), Azure returns 2 pages
- academic arxiv: 27 pages, Azure returns 2 pages
- legal docs: 4-5 pages, Azure returns 2 pages
- Different PDF producers (Aspose, pdfTeX, LibreOffice) all affected

**Root cause**: Most likely Azure Free Tier (F0) which limits to 2 pages per document
- Resource: `pdf-bench-docai.cognitiveservices.azure.com`
- User has $200 credit but resource may be on F0 tier
- Need to check/upgrade to S0 (Standard) in Azure Portal

**Azure results by corpus (with 2-page limit)**:
- HR (1-page docs): 86% - works correctly
- Synthetic (1-2 pages): 89% - works correctly
- Invoices (2 pages): 44% - ground truth issue, not page limit
- CUAD (11+ pages): 36% - page limit truncation
- Legal (4-5 pages): 42% - page limit truncation
- Academic (27 pages): 3% - severe truncation
