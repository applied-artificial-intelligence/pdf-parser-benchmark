1. **Dataset is split across sources**:
   - Images: Available on HuggingFace `ajimeno/PubTabNet`
   - Annotations: Separate JSONL files (location unclear)

2. **HuggingFace dataset issues**:
   - `ajimeno/PubTabNet` has only images (PNG), no HTML annotations
   - `bsmock/pubtables-1m` is wrong dataset (XML-based, not PubTabNet)
   - Tried downloading with slicing (`split='validation[:5]'`) but triggered full 18-file download

3. **Format**:
   - Images: PNG files of tables
   - Annotations: JSONL format with HTML structure tokens + bounding boxes
   - Need to match images to annotations by filename/ID
