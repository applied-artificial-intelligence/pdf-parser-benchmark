## Key Findings from Survey Research

From `.claude/reference/benchmark_survey.md`:

**Benchmarks to Use** (all have permissive licenses for leaderboard publishing):
1. **DocLayNet** - 81K pages, multi-domain, CDLA-Permissive
   - Metric: mAP @ IoU for layout segmentation
2. **PubTabNet** - 568K tables, Public license
   - Metric: TEDS (Tree-Edit-Distance-based Similarity)
3. **OmniDocBench** - CVPR 2025, Apache-2.0
   - Metric: Composite score (Text EditDist + Table TEDS + Formula CDM)

**Key Insight**: We CAN publish leaderboard scores using these benchmarks. License restrictions only apply to redistributing data or commercial use of data itself. We can download, benchmark, and publish scores while citing properly.
