## Recent Decisions

### 1. Use Established Library Instead of Custom Converter

**Decision**: Replace custom `sec_html_to_markdown.py` with `markdownify` library for SEC ground truth generation

**Rationale**:
- Custom converter only extracted tables, missed body text (95% content loss)
- `markdownify` is mature, well-tested, handles SEC HTML properly
- Immediate 44.7 percentage point improvement in similarity
- No need to reinvent the wheel

**Impact**: All SEC ground truth files regenerated successfully

### 2. Ground Truth Lookup Strategy

**Decision**: Implement corpus-specific lookup logic based on directory structure patterns

**Implementation**:
- arXiv: `{pdf_dir}/ground_truth.md`
- GOV.UK: `{pdf_dir}/../ground_truth/{filename}.md`
- SEC EDGAR: `{pdf_dir}/../ground_truth/sec_{cik_no_zeros}_{accession}.md`
- Synthetic: `{pdf_path}.md` (alongside PDF)

**Why**: Each corpus has different historical file organization

### 3. XBRL Metadata Handling

**Decision**: Strip hidden XBRL `<div style="display:none">` blocks before HTML→Markdown conversion

**Rationale**:
- SEC HTML contains massive inline XBRL metadata (machine-readable financial data)
- PDFs don't contain this metadata (only human-readable content)
- Stripping reduces HTML from 2.7MB → 2.4MB
- Creates fair comparison for PDF parsers

**Implementation**: Added to both `sec_html_to_markdown.py` and markdownify workflow

## Technical Notes

### Markdownify Usage

```python
from markdownify import markdownify as md
from bs4 import BeautifulSoup

# Strip XBRL first
soup = BeautifulSoup(html, 'html.parser')
for elem in soup.find_all('div', style=lambda x: x and 'display:none' in x.lower() if x else False):
    elem.decompose()

# Convert to markdown
markdown = md(str(soup), heading_style='ATX')
```

**Parameters**:
- `heading_style='ATX'`: Use `#` format (not underlines)
- Other defaults work well for SEC HTML
