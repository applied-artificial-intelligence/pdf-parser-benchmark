### Parser API Patterns Discovered

**Text extraction only**:
```python
# pypdfium2, pypdf, pypdf2, pdfminer - similar pattern
from library import Reader/Parser
text = extract_or_read(pdf_path)
```

**Markdown-optimized**:
```python
# pymupdf4llm
import pymupdf4llm
md = pymupdf4llm.to_markdown(pdf_path)
```

**Async pattern**:
```python
# kreuzberg
from kreuzberg import extract_file
result = await extract_file(pdf_path)
text = result.content
# Need asyncio.run() wrapper in sync context
```

**Java-based**:
```python
# tika
from tika import parser
file_data = parser.from_file(pdf_path)
text = file_data['content']
```

**Document converter**:
```python
# docling
from docling.document_converter import DocumentConverter
converter = DocumentConverter()
result = converter.convert(pdf_path)
md = result.document.export_to_markdown()
```
