## Recent Decisions

### 1. Use Pandoc (Not Custom Script)

**Decision**: Convert ar5iv HTML to Markdown using `pandoc` with minimal post-processing

**Rationale**:
- ✅ Perfect equation extraction (LaTeX from MathML alt-text)
- ✅ Already installed, battle-tested
- ✅ Fast (5 papers in <1 second)
- ✅ Good enough for benchmarking (similarity metric tolerates formatting quirks)

**Alternative considered**: Build custom `ar5iv_to_markdown.py` with BeautifulSoup
**Why rejected**: Unnecessary complexity, Pandoc already does the job

### 2. ar5iv is Legitimate Service (Not Web Scraping)

**User clarification**: "are you actually using https://ar5iv.labs.arxiv.org/? you should not be scraping. this should work quite well"

**Validation**:
- ✅ ar5iv is official labs.arxiv.org service
- ✅ Converts LaTeX → HTML5 with semantic MathML
- ✅ 100% success rate on our 5-paper sample
- ✅ Perfect for ground truth (LaTeX source → HTML, not approximation)

**Why HTML scraping failed but ar5iv works**:
- GOV.UK/SEC HTML: Presentation derivatives (2.6%, 29% similarity)
- ar5iv HTML: Converted from **authoring format** (LaTeX source)
- **Key principle**: Ground truth must come from authoring format, not presentation

### 3. Marker Supports Local LLMs via Ollama

**Discovery**: Marker has `--llm_service` flag supporting multiple LLM backends

**Supported services**:
1. ✅ **Ollama** (local, free) - `marker.services.ollama.OllamaService`
2. Google Gemini (commercial) - `marker.services.gemini.GoogleGeminiService`
3. OpenAI (commercial) - `marker.services.openai.OpenAIService`
4. Claude (commercial) - `marker.services.claude.ClaudeService`
5. Azure OpenAI (commercial) - `marker.services.azure_openai.AzureOpenAIService`

**Default Ollama model**: `llama3.2-vision` (multimodal, can see PDF images)

**Impact**: Can test Marker with LLM enhancement without any API costs
