## Technical Details

### Marker+Ollama Fix (GitHub #907)

**Problem**: Ollama rejects JSON schemas with `$ref` references
```python
# Marker sends:
format_schema = {
    "type": "object",
    "properties": schema["properties"],  # Contains $ref: "#/$defs/BlockSchema"
    "required": schema["required"]
}
# Result: 500 Server Error from Ollama
```

**Solution**: Flatten schema by resolving all `$ref` references
```python
def flatten_schema(schema):
    if not isinstance(schema, dict):
        return schema

    defs = schema.pop('$defs', {})

    def resolve_refs(obj):
        if isinstance(obj, dict):
            if '$ref' in obj:
                ref_name = obj['$ref'].split('/')[-1]
                return resolve_refs(defs.get(ref_name, {}))
            else:
                return {k: resolve_refs(v) for k, v in obj.items()}
        elif isinstance(obj, list):
            return [resolve_refs(item) for item in obj]
        return obj

    return resolve_refs(schema)
```
