**Decision**: Create wrappers that adapt metric signatures to runner expectations

**Pattern established**:
```python

        # Parse/convert inputs as needed
        # Call actual metric
        # Return float (or NaN on error)

        return float("nan")
```

**Applied to**:
- `_tree_similarity_wrapper()` - Parse markdown to AST
