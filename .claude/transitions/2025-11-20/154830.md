### 2. Text Similarity Metric Limitations (KNOWN)

**Current**: Using `difflib.SequenceMatcher` (edit distance, case-insensitive)

**Issues**:
- Doesn't account for structure (tables, lists, headings)
- Whitespace handling arbitrary
- Reading order differences penalized equally to content errors
- No distinction between critical vs minor errors

**Better Metrics Identified**:
- **mAP** (mean Average Precision) - Layout detection
- **TEDS** (Tree Edit Distance-based Similarity) - Table structure
- **Element-level F1** - Precision/recall on document elements
- **chrF++** - Character n-gram F-score

**Status**: Placeholders exist in `pdf_bench/metrics/` but not integrated
**Decision**: Upgrade to proper metrics is Phase 3 work (after baseline completion)
