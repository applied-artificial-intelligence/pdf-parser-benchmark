```python
_ast_parser = MarkdownASTParser()

def _tree_similarity_wrapper(ground_truth: str, prediction: str) -> float:
    gt_ast = _ast_parser.parse(ground_truth)
    pred_ast = _ast_parser.parse(prediction)
    return tree_similarity(gt_ast, pred_ast)

def _element_f1_wrapper(ground_truth: str, prediction: str) -> float:
    gt_ast = _ast_parser.parse(ground_truth)
    pred_ast = _ast_parser.parse(prediction)
    scores = element_f1_score(gt_ast, pred_ast)
    return scores['overall']['f1']  # Extract F1 from dict
```

## Recent Decisions

### 1. Multi-Metric Evaluation is Essential

**Decision**: Implement and report 6 metrics instead of just edit_similarity

**Rationale**:
- Text similarity alone is misleading (high text, low structure)
- Different parsers excel at different dimensions
- Users need to understand trade-offs (speed vs accuracy vs structure)
- Academic rigor requires multi-dimensional assessment

**Implementation**: Created wrapper functions for AST-based metrics

### 2. Wrapper Functions for AST Metrics

**Problem**: tree_similarity and element_f1_score expect parsed AST objects, but runner passes strings

**Solution**: Created wrapper functions that:
1. Parse markdown strings to AST using MarkdownASTParser
2. Call original metric with parsed AST
3. Return float (catching exceptions → NaN)

**Why not change runner**: Other metrics work with strings, changing runner would break them

### 3. Report Overall F1 from element_f1_score

**Problem**: element_f1_score returns dict with 'overall' and 'per_element' keys, not a float

**Solution**: Extract `scores['overall']['f1']` in wrapper

**Alternative considered**: Return all per-element scores (rejected - too verbose for summary)

### 4. Synthetic + External Corpus Strategy

**Decision**: Keep synthetic corpus as primary, add external benchmarks as Phase 3

**Rationale**:
- Synthetic: Perfect ground truth, rapid iteration, controlled testing
- External: Real-world diversity, academic credibility
- Both needed for comprehensive evaluation

**Next**: Integrate OmniDocBench (requires JSON → Markdown converter)

### 5. Structure Preservation Critical Gap

**Finding**: ALL parsers lose 69-79% of document structure

**Impact**: This is a **major research finding** worth publishing
- Challenges assumption that high text similarity = good parsing
- Explains why downstream tasks (RAG, search) struggle with parsed PDFs
- Validates need for structure-aware parsers

**Action**: Highlight this in all documentation and presentations

### 2. TEDS Scores Suspiciously Perfect

**Finding**: ALL parsers score 100% on TEDS (table structure)

- Parsers genuinely perfect at tables (unlikely given 21-31% structure scores)

**Investigation needed**:
- Examine sample tables in test corpus
- Run TEDS on complex tables with merged cells, nested headers

**Impact**: If TEDS is broken, table evaluation is invalid
