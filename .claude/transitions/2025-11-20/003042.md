## Environment Variables for Commercial Parsers

**AWS Textract**:
```bash
export AWS_PROFILE=wyden
# OR
export AWS_ACCESS_KEY_ID=...
export AWS_SECRET_ACCESS_KEY=...
export AWS_REGION=us-east-1
```

**Azure Document Intelligence**:
```bash
export AZURE_DOCUMENT_INTELLIGENCE_ENDPOINT=https://your-resource.cognitiveservices.azure.com/
export AZURE_DOCUMENT_INTELLIGENCE_KEY=your-api-key
```

**Google Cloud Document AI**:
```bash
export GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account.json
export GOOGLE_CLOUD_PROJECT=your-project-id
export GOOGLE_CLOUD_LOCATION=us
```

**Databricks**:
```bash
export DATABRICKS_HOST=https://your-workspace.cloud.databricks.com
export DATABRICKS_TOKEN=your-token
export DATABRICKS_CLUSTER_ID=your-cluster-id
```

**Landing AI**:
```bash
export LANDING_AI_API_KEY=your-api-key
export LANDING_AI_ENDPOINT=https://api.landing.ai/v1/document
export LANDING_AI_PROJECT_ID=your-project-id
```
