## Technical Context

### SEC EDGAR URL Patterns
```
# Index page
https://www.sec.gov/Archives/edgar/data/{CIK}/{ACCESSION_CLEAN}/{ACCESSION}-index.htm

# Primary filing document (two formats)
https://www.sec.gov/Archives/edgar/data/{CIK}/{ACCESSION_CLEAN}/{FILENAME}.htm
https://www.sec.gov/ix?doc=/Archives/edgar/data/{CIK}/{ACCESSION_CLEAN}/{FILENAME}.htm

# Where:
# CIK = Company ID (e.g., 320193 for Apple)
# ACCESSION = Filing ID with hyphens (e.g., 0000320193-21-000105)
# ACCESSION_CLEAN = Accession without hyphens (e.g., 000032019321000105)
# FILENAME = Actual filing (e.g., aapl-20210925.htm)
```

### SEC Rate Limiting
- **Official limit**: 10 requests/second
- **Reality**: Very aggressive blocking
- **Symptoms**: 403 Forbidden, "undeclared automated tool" error page
- **Block duration**: 12-24 hours for the IP address
- **Bypass**: Use Chrome DevTools MCP (real browser, not detected as bot)
