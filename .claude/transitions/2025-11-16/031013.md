## Recent Decisions

### 1. Multiprocessing Strategy
**Decision**: Use Python's multiprocessing with worker function instead of concurrent.futures
**Rationale**: Better control over process pool, easier progress tracking, standard library
**Implementation**: Standalone `_worker_run_single()` function that recreates parsers in worker processes

### 2. Parser Options Handling
**Decision**: Best-effort attribute extraction from parser instances
**Rationale**: Avoids need for parsers to implement serialization, works for common patterns
**Limitation**: May need enhancement for parsers with complex initialization (API keys, credentials)
**Current Approach**: Check for `_name`, `_should_fail`, `_output_content` attributes

### 3. Progress Bar Integration
**Decision**: Conditional Rich import with graceful fallback
**Rationale**: Rich is a dev dependency, not all environments may have it
**Benefit**: Beautiful progress bars when available, silent fallback otherwise

### 4. Worker Count Configuration
**Decision**: Three modes - auto (0), sequential (1), custom (N)
**Rationale**: Flexibility for different use cases (debugging vs production)
**Default**: Auto-detect CPU count, capped at 8 for safety

### 5. Dataclass Organization
**Decision**: Define dataclasses before worker function
**Rationale**: Worker function uses DocumentResult, must be defined first for pickle
**Learning**: Multiprocessing requires careful ordering of definitions

**Serialization Challenge**:
`DocumentResult.metrics` is `dict[str, float]` but may contain `float("nan")`.
JSON doesn't have NaN, need to handle:
```python
import json
import math

# Option 1: Convert NaN to null
def serialize_metrics(metrics):
    return {k: (None if math.isnan(v) else v) for k, v in metrics.items()}

# Option 2: Convert NaN to string "NaN"
def serialize_metrics(metrics):
    return {k: ("NaN" if math.isnan(v) else v) for k, v in metrics.items()}
```

### Configuration System

**Example Usage**:
```python
from pathlib import Path
from pdf_bench.loader import load_benchmark_config
from pdf_bench.runner import BenchmarkRunner

# Load config (validates, resolves paths, instantiates parsers)
config = load_benchmark_config(Path("benchmarks/quick_test.yaml"))

# Run benchmark (sequential)
runner = BenchmarkRunner(config, parallel_workers=1)
results = runner.run()

# Run benchmark (parallel with 4 workers)
runner = BenchmarkRunner(config, parallel_workers=4)
results = runner.run()

# Access results
print(f"Total results: {len(results.results)}")
print(f"Successes: {results.success_count}")
for result in results.results:
    if result.success:
        print(f"{result.parser_name} on {result.document_id}:")
        print(f"  Metrics: {result.metrics}")
```
