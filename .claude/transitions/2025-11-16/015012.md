### Marker Implementation
**Decision**: Use subprocess with full venv path to marker_single CLI
**Rationale**: Clean separation, leverages official CLI, handles GPU automatically
**Implementation**: `.venv/bin/marker_single` with temp output directory management

### Unstructured Strategy
**Decision**: Default to 'fast' strategy with configurable options
**Rationale**:
- Fast strategy works without tesseract (minimal dependencies)
- Good balance of speed (0.2s) and accuracy (100% text)
- Users can opt into hi_res if needed
**Trade-off**: List formatting not perfect in fast mode, but acceptable

### Custom Markdown Conversion (Unstructured)
**Decision**: Implement custom `_elements_to_markdown()` method
**Rationale**: Unstructured's element output needs proper markdown formatting
**Benefits**: Control over structure, proper spacing, heading/list handling

### Cache Key Strategy
**Decision**: Include strategy in Unstructured cache key (`version-strategy`)
**Rationale**: Different strategies produce different output, need separate caching
**Implementation**: `cache_version = f"{self.version}-{self._strategy}"`
