## Recent Decisions

### 1. Persistence: NaN Handling in JSON
**Decision**: Convert NaN to null in JSON, restore on load
**Rationale**: JSON doesn't support NaN natively
**Implementation**: `_serialize_metrics()` and `_deserialize_metrics()` functions
**Benefit**: Round-trip equality guaranteed, clean JSON output
