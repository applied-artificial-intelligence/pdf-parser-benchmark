- Builds confidence when both agree

- Add new task for ar5iv HTML5→Markdown converter
- Can run in parallel (independent implementations)

### 2. SEC EDGAR Library Context

**User Reference**: `/home/stefan/ml3t/ch05_fundamental_and_alternative_data/code/`

**Key Patterns**:
- Uses `edgartools` library (imported as `edgar`)
- Proper SEC compliance: User-Agent headers, rate limiting
- Bulk financial statement downloads (Financial Statement and Notes datasets)
- TSV→Parquet conversion for efficiency

**Decision**: Built from scratch with BeautifulSoup4 rather than adding `edgartools` dependency. More control, lighter weight.

### 3. Three-Tier Table Classification (TASK-055)

**Innovation**: Instead of binary simple/complex, use three tiers:
- **SIMPLE**: Single header, no merging → GitHub Flavored Markdown
- **MEDIUM**: Multi-level headers OR some merging → HTML preserved
- **COMPLEX**: Nested tables OR XBRL OR heavy merging → HTML

**Benefits**:
- Balances readability vs preservation
- Prevents over-simplification
- Handles intermediate cases gracefully

### 4. Currency Normalization Strategy

**Decision**: Normalize by default for consistency
- Remove `$`: `$1,234` → `1234`
- Remove commas: `1,234,567` → `1234567`
- Convert negatives: `($123)` → `-123`

**Limitation Documented**: Dollar sign context (in headers) not preserved. Acceptable for benchmarking use case.
