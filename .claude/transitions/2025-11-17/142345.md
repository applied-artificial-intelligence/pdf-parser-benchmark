### Cost Tracking Architecture
**Decision**: Implement cost tracking at two levels:
1. **Parser Level**: Each commercial parser tracks own costs (`get_total_cost()`, `last_parsing_cost`)
2. **System Level**: `CostEstimator` and `CostReport` provide aggregate tracking

**Rationale**: Enables both per-document transparency and benchmark-wide cost analysis
**Implementation**: Consistent API across AWS Textract and Azure DI parsers

## Technical Notes

### Cost Tracking API Design
All commercial parsers expose consistent cost tracking interface:
```python
parser = AWSTextractParser()  # or AzureDocumentIntelligenceParser()

# Parse PDF
result = parser.parse(pdf_path, output_dir)

# Check costs
print(f"Last parse: ${parser.last_parsing_cost:.4f}")
print(f"Total cost: ${parser.get_total_cost():.2f}")
print(f"Total pages: {parser.get_total_pages()}")
```

### CostEstimator Usage
```python
from pdf_bench.utils.cost_tracking import CostEstimator

estimator = CostEstimator()

# Estimate before parsing
estimate = estimator.estimate_cost(pdf_list, "aws_textract")
print(f"Estimated: ${estimate.total_cost:.2f} for {estimate.total_pages} pages")

# Check budget
within_budget, estimate = estimator.check_budget(pdf_list, "aws_textract", max_cost=10.0)
if not within_budget:
    raise RuntimeError(f"Would exceed budget! Estimated: ${estimate.total_cost:.2f}")
```

### CostReport Usage
```python
from pdf_bench.utils.cost_tracking import CostReport

report = CostReport()

# Track after each parse
report.add_parse_result("aws_textract", "doc1.pdf", pages=10, cost=0.015)
report.add_parse_result("azure_document_intelligence", "doc2.pdf", pages=20, cost=0.030)

# Generate summary
print(report.summary())
# Shows: total cost, total pages, per-parser breakdown
```
