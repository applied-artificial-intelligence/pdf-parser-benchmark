## Technical Notes

### SEC EDGAR Download Process Used

1. **Find accession numbers** from company metadata
2. **Get filing index** from SEC viewer: `https://www.sec.gov/cgi-bin/viewer?action=view&cik={cik}&accession_number={accession}`
3. **Extract primary document filename** from index (e.g., `bac-1231201910xk.htm`)
4. **Download primary document** from Archives: `https://www.sec.gov/Archives/edgar/data/{cik}/{accession_no_dashes}/{filename}`
5. **Convert HTML→Markdown** using `builders/sec_html_to_markdown.py`

**Filename patterns observed**:
- Annual 10-K: `{ticker}-{MMDDYYYY}{10xk}.htm` (e.g., `bac-1231201910xk.htm`)
- Quarterly 10-Q: `{ticker}-{YYYYMMDD}.htm` (e.g., `wfc-20200930.htm`)

### Ground Truth Lookup Logic

```python
# SEC EDGAR
gt_dir = pdf_path.parent.parent / "ground_truth"
# Handle CIK leading zeros: sec_bac_0000070858... → sec_70858_0000070858...
accession = parts[-1]  # "0000070858-20-000011"
cik_no_zeros = accession.split("-")[0].lstrip("0")  # "70858"
alt_name = f"sec_{cik_no_zeros}_{accession}.md"

# arXiv
gt_path = pdf_path.with_suffix(".md")

# GOV.UK
gt_dir = pdf_path.parent.parent / "govuk_markdown"
gt_path = gt_dir / pdf_path.with_suffix(".md").name
```

- **CER**: Character error rate
- **Parse time**: Wall-clock time for extraction
- **Success rate**: Percentage of successful parses
