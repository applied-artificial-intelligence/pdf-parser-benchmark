## Technical Notes

### pyproject.toml Structure (Important!)

**Correct order** (hatchling requirement):
```toml
[project]
name = "..."
version = "1.0.0"
dependencies = [...]

[project.urls]
Homepage = "..."

[project.optional-dependencies]
...

[project.scripts]
...
```

**Wrong**: Putting `dependencies` after `[project.urls]` causes build error.
