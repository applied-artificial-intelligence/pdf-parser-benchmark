### Issues Fixed This Session

**Problem**: Benchmark initially only discovered 31 documents instead of 278

**Root Causes** (multiple layers):
1. **Metadata schema mismatch**: Business documents used `document_id` instead of `doc_id`
2. **Missing required fields**: Business documents lacked `corpus`, `source_url`, `domain` fields
3. **Directory structure mismatch**: Business corpus used subdirectories (`metadata/`, `pdfs/`, `ground_truth/`) vs flat structure
4. **Validation too strict**:
   - `VALID_DOMAINS` only allowed `['gov-uk', 'sec-edgar']` for business corpus
   - `source_url` validation rejected `generated://` URLs

**Solutions Implemented**:

1. **Added missing metadata fields** to all 242 business documents:
   ```python
   # Fixed 242 business metadata files
   - Added: corpus: business
   - Added: source_url: generated://{doc_id}
   - Added: domain: legal|invoices|hr (inferred from path)
   - Added: doc_id (copied from document_id or id field)
   ```

2. **Updated loader** (`pdf_bench/loader.py:209-226`):
   ```python
   # Pattern 1: Same directory (synthetic)
   pdf_path = metadata_path.parent / f"{file_stem}.pdf"
   gt_path = metadata_path.parent / f"{file_stem}.md"

   # Pattern 2: Subdirectories (business)
   if not pdf_path.exists():
       corpus_root = metadata_path.parent.parent
       pdf_path = corpus_root / "pdfs" / f"{file_stem}.pdf"
       gt_path = corpus_root / "ground_truth" / f"{file_stem}.md"
   ```

3. **Relaxed validation** (`pdf_bench/utils/metadata.py` and `pdf_bench/config.py`):
   ```python
   # Extended VALID_DOMAINS
   "business": ["gov-uk", "sec-edgar", "legal", "invoices", "hr"]
   "synthetic": ["pandoc", "libreoffice", "tables", "lists", "multicolumn", "mixed"]

   # Relaxed source_url validation
   if not (url.startswith("http://") or url.startswith("https://")
           or url.startswith("generated://")):  # Added this
   ```
