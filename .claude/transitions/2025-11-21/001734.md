## Important Context for Continuation

### Checkpoint Feature Details

**How It Works**:
1. Every 20 results, saves to `{output}.checkpoint.json`
2. On restart, loads checkpoint and identifies completed (parser, doc_id) pairs
3. Filters out completed tasks, runs only remaining
4. Progress preserved through crashes, timeouts, interrupts

**Usage**:
```bash
# First run or resume - same command
uv run python pdf_bench/main.py run CONFIG.yaml -o OUTPUT.json

# If interrupted, just rerun - it auto-detects checkpoint
# Output: "✓ Loaded checkpoint: N tasks already complete"
# Output: "→ Running M tasks (N already done)"
```

**Benefits**:
- 8-hour benchmark protected from data loss
- Crash at hour 6 → resume completes in 2 hours
- Minimal overhead (~100ms per checkpoint)
