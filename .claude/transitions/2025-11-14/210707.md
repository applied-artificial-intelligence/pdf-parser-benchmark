## Recent Decisions

### 1. AST Parser Design (TASK-019)
**Decision**: Use mistune 3.x with GFM plugins by default

**Rationale**:
- Modern, actively maintained (released August 2025)
- Clean API with `renderer='ast'` support
- GFM extensions (tables, strikethrough) widely used
- Type-safe with explicit cast for mypy compliance

**Implementation**: Created synthetic "document" root for multi-root ASTs, filters blank_line tokens from counts

### 2. Tree-Edit Distance Algorithm (TASK-020)
**Decision**: Use Zhang-Shasha via zss library (not APTED)

**Rationale**:
- Optimal for ordered trees (Markdown is ordered)
- Fast enough for typical documents (<1ms for <500 nodes)
- Well-tested, mature library
- Simpler than APTED (which is more accurate but slower)

**Implementation**: Smart node labels distinguish H1 from H2, ordered from unordered lists, code languages

### 3. Element F1 Scoring (TASK-021)
**Decision**: Provide both macro and micro averaging

**Rationale**:
- Macro: Equal weight per element type (fair to rare elements)
- Micro: Weighted by frequency (overall accuracy)
- Users need both perspectives

**Implementation**: True positives = min(gt_count, pred_count), handles zero counts gracefully
