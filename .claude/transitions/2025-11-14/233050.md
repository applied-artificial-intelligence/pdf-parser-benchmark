**Implementation**:

- `cell_accuracy()` for simple accuracy metric
- `CellF1Scores` dataclass for structured results
- Intelligent table padding for mismatched dimensions
- Text normalization (Unicode, whitespace, ligatures)
- Works with both `GFMTable` and raw 2D arrays

**Key Algorithm**:
- TP: Non-empty cells that match
- FP: Prediction has content, ground truth doesn't or differs
- FN: Ground truth has content, prediction doesn't or differs
- Empty-empty matches don't count as TP (only meaningful cells)

### Implementation Approach
1. **GFM Table Parser Design** (TASK-024):
   - Decided to leverage existing `MarkdownASTParser` from TASK-019 instead of regex
   - Rationale: Reliable GFM parsing, handles edge cases, avoids code duplication
   - Uses mistune's table plugin for robust extraction

2. **Cell Content F1 Counting** (TASK-025):
   - Empty-empty cell matches don't count as TP
   - Rationale: Only meaningful cells should contribute to metrics
   - When cells differ, count as both FP and FN
   - Accuracy = TP / (TP + FP + FN) to account for this

3. **Table Dimension Handling** (TASK-025):
   - Pad tables to matching dimensions for comparison
   - Empty table gets padded to match non-empty table's dimensions
   - Rationale: Enables fair cell-by-cell comparison with mismatched tables
