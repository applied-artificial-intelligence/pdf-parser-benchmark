## Recent Decisions

### Validation Script Architecture (TASK-017)
**Decision**: Support both Pandoc and DOCX metadata formats in validator

**Rationale**:
- Different generation pipelines use different metadata structures
- Pandoc uses `file_paths` field, DOCX uses `files` field
- Validation must handle both transparently
- Maintains backward compatibility

**Implementation**: Conditional logic in `_validate_yaml_schema()` and `_validate_file_existence()`

### Manual Review Approach (TASK-018)
**Decision**: Systematic spot checks rather than exhaustive line-by-line comparison

**Rationale**:
- Automated validation already verifies hashes and parseability
