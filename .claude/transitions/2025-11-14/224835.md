**Decision**: Implement from scratch with BeautifulSoup + smart span handling

**Rationale**:
- Clean separation between normalization and extraction
- Handles colspan/rowspan by expansion to regular 2D grid
- Normalization: lowercase tags/attributes, sort attributes, whitespace handling
- Foundation for TEDS metric integration

**Implementation**:
- `TableCell` class tracks span information
- `_expand_spans_to_grid()` converts irregular tables to regular grids
- 42 comprehensive tests including edge cases (malformed HTML, Unicode, large spans)

### 2. TEDS Implementation Approach (TASK-023)
**Decision**: Implement TEDS from scratch using existing dependencies (zss + BeautifulSoup)

**Rationale**:
- No well-maintained `table-recognition-metric` library on PyPI
- We already have zss (tree edit distance) and BeautifulSoup
- Full control over implementation allows customization
- Simpler dependency management

**Implementation**:
- Tree encoding: `td[2x1]` for colspan/rowspan information
- Two scoring variants: structure-only and content-aware
- Formula: `TEDS = 1 - (TreeEditDistance / max(|T_pred|, |T_gt|))`
- 35 tests with 93% coverage
