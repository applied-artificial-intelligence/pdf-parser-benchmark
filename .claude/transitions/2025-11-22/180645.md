### Key Issue References

- **Memory leak**: https://github.com/docling-project/docling/issues/2209
  - Status: OPEN (not fully resolved in docling)
  - Workaround: Call `unload()` after each conversion

- **Memory management best practices**: https://github.com/docling-project/docling-serve/issues/366
  - Use `result.input._backend.unload()` after processing
  - Set OMP_NUM_THREADS, MKL_NUM_THREADS=2 before importing docling
  - Use `generate_parsed_pages=False` and `page_batch_size` to limit memory
